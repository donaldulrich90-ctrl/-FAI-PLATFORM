Placez ici vos vidéos et vos fichiers audio.

Recommandations :
- format MP4 (H.264 + AAC) ;
- durée de 15 à 30 secondes ;
- poids inférieur à 5 Mo ;
- résolution 720p maximum ;
- pas de lecture automatique avec le son.

Noms déjà préparés dans js/media-config.js :
- promo.mp4 pour la vidéo promotionnelle ;
- annonce.mp3 pour l’annonce audio.

Après avoir copié un fichier, ouvrez js/media-config.js et passez
la propriété enabled correspondante de false à true.
